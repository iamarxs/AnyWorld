    Create the scenario

    Each line can be either a random event or narrative guidance:
    • Random Events: Define a chance (0–100%) and a trigger. Example: "Add a 10% chance every round that a thief appears."
    • Narrative Guidance: Instructions to steer the AI's style, tone, or direction. Example: "The setting is gothic.", or "Steer responses toward the absurd, as if the scenario happened in a universe that does not conform to basic logic."
    Each instruction is processed on its own line. Python rolls the chance for events; the AI follows the narrative guidance to shape the story.
